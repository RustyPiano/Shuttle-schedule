# 校内班车时刻表

查询院际班车（8号线、理学院、系统、空天、气海、前沿）、三号院环线和一号院环线的发车时间。

选择乘车方向后，页面按当前时间汇总各线路的下一班车。日期可直接选择“今天、明天、周六、周日”，下方显示具体日期；周日当天的周末按钮指向下一个周末。选择今天默认从当前时间查询，其他日期默认从首班查看，也可调整出发时间。每个班次显示线路名称、发车说明和车辆数量，有站点资料的线路可展开查看常规停靠站点。两条环线分别查询，一号院环线仅工作日运行。

节假日和调休日期使用 [chinese-days](https://github.com/vsme/chinese-days) 随应用附带的数据，当前收录至 2026 年；2026 年日期已核对[国务院办公厅通知](http://www.scio.gov.cn/zdgz/jj/202511/t20251110_938367.html)。调休上班日按工作日时刻表查询。节假日期间的班车安排尚未确认，页面显示“班车安排待确认”；计算下一班车时遇到这些日期也会停止并提示待确认。尚未收录节假日资料的年份同样显示待确认。新增年份需更新 chinese-days 并重新构建发布。

```bash
npm install
npm run dev
npm test
npm run build
```

时刻和站点都在 `src/data.ts`。三号院环线时刻按根目录的 Excel 表《三号院环线发车时刻表》（2025年9月18日开始执行）录入；一号院环线按提供的《一号院内环线发车时刻表》照片录入，共 28 班，首班 07:30，末班 18:00。
