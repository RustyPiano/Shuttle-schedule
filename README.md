# 校内班车时刻表

查询院际班车（8号线、理学院、系统、空天、气海、前沿）、三号院环线和一号院环线的发车时间。

选择乘车方向后，页面按当前时间汇总各线路的下一班车。可指定出发日期和时间；每个班次显示线路名称、发车说明和车辆数量，有站点资料的线路可展开查看常规停靠站点。两条环线分别查询，一号院环线仅工作日运行。

```bash
npm install
npm run dev
npm test
npm run build
```

时刻和站点都在 `src/data.ts`。三号院环线时刻按根目录的 Excel 表《三号院环线发车时刻表》（2025年9月18日开始执行）录入；一号院环线按提供的《一号院内环线发车时刻表》照片录入，共 28 班，首班 07:30，末班 18:00。
